# rebot

This repository uses Git submodules for third-party dependencies (`third-party/reBot-DevArm`, `third-party/lerobot`).

## Clone this repository

**Recommended** (fetch all submodules in one step):

```bash
git clone --recurse-submodules git@github.com:Alwin-Yang/rebot.git
```

**Already cloned but submodules not initialized**:

```bash
git submodule update --init --recursive
```
